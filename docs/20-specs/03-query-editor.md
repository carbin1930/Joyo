# spec-03：SQL 编辑器

- 规格编号：spec-03
- 功能名称：SQL 编辑器
- 所属版本：v0.1
- 状态：已定稿
- 依赖 spec：spec-01（连接会话）

## 1. 功能描述

基于 Monaco Editor 的 SQL 编辑与执行区域：语法高亮、执行选中/光标语句、多语句依次执行、执行状态与错误展示（关联 PRD US-04）。查询历史在 v0.2 实现，本 spec 只预留入口。

## 2. 界面设计

主区域上半部为**编辑器面板**：

- Monaco Editor，language=`sql`，主题跟随应用（浅色/深色）
- 顶部工具条：`运行` 按钮（主色）、运行目标提示（"选中语句" / "全部语句"）、行数限制下拉（100 / 1000 / 10000，默认 1000）
- 底部状态条：当前连接名 · 默认数据库选择器（下拉列出该实例所有库）

**执行交互**：

- `Ctrl+Enter`：执行选中内容；无选中则执行光标所在语句（按分号边界拆分定位）
- 多语句：按分号拆分为语句队列，依次执行；结果区显示多个结果 Tab（每个语句一个），编号如 `结果 1/3`
- 执行中：运行按钮变为 `停止`（v0.1 仅置灰执行按钮 + loading 遮罩，中断功能 v0.4 再做）
- 非查询语句（DDL/DML）：结果区显示"执行成功，影响 N 行（耗时 xx ms）"

## 3. 接口依赖

见 `rest-api.md` 查询执行节：`POST /connections/{id}/queries`。多语句拆分规则**由后端负责**（接口参数 `sql` 传原文），前端不实现 SQL 解析。

## 4. 行为细节

1. 语句拆分：后端按分号拆分，忽略字符串/注释/反引号内的分号
2. 执行队列中某条语句失败：**中止后续语句**，已成功的结果保留展示，失败语句的错误单独展示
3. 结果集行数上限：超限截断，返回 `truncated: true` 与 `totalKnown`，前端在结果 Tab 标题旁显示"已截断"徽标
4. 编辑器内容在切换连接时不丢失；每个连接独立保存草稿（内存态即可，不落盘）
5. 快捷键：`Ctrl+S` 仅阻止默认行为（v0.2 另存为代码片段），`Ctrl+/` 行注释

## 5. 边界情况

| 场景 | 期望表现 |
|---|---|
| 空内容/纯注释执行 | 提示"没有可执行的语句"，不调用接口 |
| SQL 语法错误 | 3001，错误面板显示 MySQL 原始错误（含错误行号提示） |
| 语句执行超时（默认 30s） | 3002，结果区显示超时提示 |
| 未连接状态点运行 | 前端拦截，提示"请先连接" |
| 选中内容跨多个完整语句 | 按选中原文拆分执行 |
| 超大结果（10 万行表无 LIMIT） | 触发行数上限截断，明确提示，UI 不卡顿 |

## 6. 验收标准

- [ ] `SELECT * FROM ...` 返回结果且结果区显示耗时与行数
- [ ] 选中两条语句按 Ctrl+Enter 只执行选中的两条
- [ ] 三条语句（成功/失败/成功）依次执行，第 2 条失败后第 3 条不执行，第 1 条结果可见
- [ ] 字符串中的分号、`--` 注释中的分号不会导致错误拆分
- [ ] `UPDATE` 语句显示影响行数；`CREATE TABLE` 显示执行成功
- [ ] 超过行数上限时结果被截断且"已截断"徽标可见
- [ ] 键盘操作：Ctrl+Enter、Ctrl+/ 均生效
