# spec-04：结果网格

- 规格编号：spec-04
- 功能名称：结果网格
- 所属版本：v0.1
- 状态：已定稿
- 依赖 spec：spec-03（产生查询结果）

## 1. 功能描述

以高性能表格展示查询结果：分页、NULL 视觉区分、复制为 CSV/TSV、元信息展示（行数/耗时）（关联 PRD US-05）。基于 Tabulator 虚拟滚动，保证大结果集流畅。

## 2. 界面设计

主区域下半部为**结果面板**（上下可拖拽分割，编辑器最小占 30%）：

- 结果 Tab 条：多语句时每个语句一个 Tab（`结果 1/3`），非查询语句显示消息 Tab
- Tab 内容 = 网格 + 底部状态条
- 网格：表头 = 列名（悬停 tooltip 显示完整类型），首列窄列显示行号
- 底部状态条（左起）：`共 N 行（截断至 M 行）| 耗时 xx ms | 页码控件 [◀] 3/12 [▶] | 每页 100`

**NULL 与数据样式**：

| 值 | 展示 |
|---|---|
| NULL | 灰色斜体 `NULL`，居中 |
| 空字符串 | 空白（与 NULL 明确区分） |
| BLOB/BINARY 列名 | 单元格显示灰色 `(BLOB)`，不可复制二进制 |
| 超长文本 | 单行省略号，悬停 tooltip 全文（截断至 2000 字符） |

## 3. 接口依赖

- 首屏数据来自 spec-03 的执行接口响应（含第一页）
- 翻页：`GET /queries/{queryId}/rows?page=&pageSize=`（见 `rest-api.md`）

## 4. 行为细节

1. 分页为**后端分页**（结果缓存在后端内存，见 `data-model.md` 第 4 节），前端只请求当前页
2. 排序：v0.1 仅在当前页内存排序（状态条注明"仅本页排序"）；跨页排序 v0.4 再做
3. 复制：选中单元格/行/区域 → `Ctrl+C` 复制为 TSV；右键菜单提供"复制为 CSV / 复制为 TSV"；NULL 复制为空串
4. 列宽手动拖拽调整，布局存内存态即可
5. 结果缓存失效：新执行查询后旧 queryId 结果由后端 LRU 管理；前端翻页拿到 1002（queryId 不存在）时提示"结果已过期，请重新执行"
6. 双击单元格进入仅编辑态用于**复制**（不写库），回车/Esc 退出

## 5. 边界情况

| 场景 | 期望表现 |
|---|---|
| 0 行结果 | 网格显示"查询成功，0 行"，仍显示列头 |
| 重复列名（如 JOIN） | 后端自动重命名为 `colname_1`、`colname_2` |
| 列数超过 50 | 默认只渲染前 50 列，状态条提示"其余 N 列未显示" |
| queryId 过期 | 1002 → 提示重新执行，不白屏 |
| 数值/日期类型 | 按原始字符串展示（避免 JS 精度丢失，DECIMAL/BIGINT 不转 Number） |
| 拖拽分割条 | 连续拖动流畅，网格自适应重排 |

## 6. 验收标准

- [ ] 万行结果集翻页（100/页）流畅，无明显卡顿（虚拟滚动生效）
- [ ] NULL 显示为灰色斜体，与空字符串视觉可区分；复制为 CSV 时 NULL → 空串
- [ ] 状态条正确显示总行数、截断提示、耗时、页码
- [ ] 选中区域 Ctrl+C 得到 TSV（Excel 可直接粘贴）；右键复制 CSV 正确处理含逗号/换行的字段（加引号转义）
- [ ] DECIMAL(20,0) 大数值显示与数据库原值一致（无精度丢失）
- [ ] 重复列名场景列头唯一且数据对应正确
- [ ] 结果过期后翻页有明确提示
