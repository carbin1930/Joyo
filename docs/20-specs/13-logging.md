# spec-13：日志查看

- 规格编号：spec-13
- 功能名称：应用日志查看（F13）
- 所属版本：v0.2
- 状态：草稿（待确认）
- 依赖 spec：spec-01（会话/健康检查基础设施）

## 1. 功能描述

实机自诊断：在应用内查看 Java 后端文件日志尾部并实时滚动，不必去资源管理器翻日志文件（PRD F13）。文件日志与"打开日志目录"菜单已在 v0.1 提前落地，本期补齐"应用内查看"。

## 2. 界面设计

入口：主窗口菜单 `工具 → 应用日志`（若 v0.1 已有"打开日志目录"，新增本项并保留原项）。打开日志对话框（900×600）：

- 顶部工具行：日志文件路径（只读）｜`自动刷新` 开关（默认开）｜`复制全部`｜`打开目录`
- 主体：等宽字体只读文本区，显示尾部日志；ERROR 行红色、WARN 行黄色
- 状态：后端未就绪时显示"后端未就绪，无法读取日志"；请求失败 toast 且保持旧内容

## 3. 接口依赖

`GET /logs?tail=200`（rest-api.md 已预留，实现时补充完整契约）：

- `tail` 范围 1-2000，默认 200
- 响应 data：`{ "filePath": "...", "sizeBytes": 123456, "lines": ["...", "..."] }`
- 日志文件不存在（尚未产生）→ `lines: []`

## 4. 行为细节

1. 自动刷新：2s 轮询 `GET /logs?tail=200`；内容与上次相同则不重绘。
2. 跟随滚动：仅当滚动位置在底部时追加后自动滚到底；用户向上翻阅时暂停跟随，出现"回到底部"悬浮按钮。
3. 关闭对话框即停止轮询（组件卸载清理定时器）。
4. 复制全部：复制当前 `lines` 拼接文本。

## 5. 边界情况

| 场景 | 期望表现 |
|---|---|
| 日志文件不存在 | 空态"暂无日志" |
| 后端离线 | 顶部提示"后端离线"，内容保留最后快照 |
| tail 参数越界 | 后端按 1001 参数校验失败返回，前端 toast |
| 日志单行超长（如堆栈） | 文本区横向滚动，不折行 |

## 6. 验收标准

- [ ] 菜单打开日志页，能看到尾部 200 行且 ERROR/WARN 着色
- [ ] 触发一次 SQL 错误后 4 秒内日志自动出现该条
- [ ] 向上翻阅时视图不跳底，点"回到底部"恢复跟随
- [ ] 关闭对话框后网络请求停止
- [ ] "打开目录"在系统文件管理器中定位日志文件
