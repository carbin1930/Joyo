# Joyo 产品需求文档（PRD）

> 文档状态：已定稿 | 版本：v1.0 | 日期：2026-10-15
> 上游文档：无 | 下游文档：`roadmap.md`、`docs/20-specs/*`

## 1. 产品定位

Joyo 是一款面向个人开发者的**现代化 MySQL 桌面客户端**，追求轻快、简洁、开箱即用。

- 产品名称：Joyo（源自作者孩子的名字）
- 形态：Windows 桌面应用（后续可扩展 macOS / Linux）
- 性质：开源项目（GitHub）

## 2. 目标用户

| 用户画像 | 核心诉求 |
|---|---|
| 后端 / 全栈开发者 | 日常查询、调试、查看表结构，启动快、不卡顿 |
| 运维 / DBA（轻度） | 连接多个环境（含跳板机）、执行 DDL、导出数据 |
| 学生 / 初学者 | 界面直观、无复杂概念、免费 |

**非目标（Non-goals）**：不做 NoSQL 支持、不做数据库设计建模工具（ER 图）、不做团队协作 / 云同步、不做监控告警平台。凡是超出"个人使用的 MySQL 客户端"范围的功能，一律不做。

## 3. 功能总体规划（一次性设计，分版本落地）

### 3.1 功能总清单

| 编号 | 功能 | 说明 | 版本 | 优先级 |

| F03 | SQL 编辑器 | Monaco 编辑器，语法高亮，执行选中 / 全部语句 | v0.1 | P0 |
| F04 | 结果网格 | 分页展示、NULL 标识、复制为 CSV / TSV、耗时与行数统计 | v0.1 | P0 |
| F05 | 查询历史 | 本地持久化，可回填到编辑器 | v0.2 | P1 |

### 3.2 版本划分原则

- **v0.1 是"第一个可运行的端到端版本"**：只做 P0 四件套，验证 Electron + Spring Boot Sidecar 架构完全可行，跑通"连接 → 浏览 → 查询 → 看结果"完整链路
- 每个 spec 设计时必须考虑后续版本的扩展点，但**不实现**扩展点以外的代码
- 功能设计在 PRD 层面一次到位，避免后期返工

## 4. 用户故事（按版本）

### v0.1（核心链路）

- US-01：作为开发者，我可以保存多个 MySQL 连接（名称、主机、端口、用户名、密码），下次打开直接双击连接，不用重复输入。
- US-02：作为开发者，配置连接时可以点击"测试连接"，2 秒内告诉我能否连通及失败原因（网络不通 / 密码错误 / 超时）。
- US-03：作为开发者，连上数据库后，左侧树能展开看到所有数据库、每个库下的表，点开表能看到列名、类型、注释和建表语句。
- US-04：作为开发者，我在编辑器里写 SQL，按 Ctrl+Enter 执行选中（或光标所在）语句，结果在下方网格展示，能看到耗时和行数。
- US-05：作为开发者，查询结果超过一屏时可以翻页，NULL 值有明显的视觉区分，我可以选中单元格复制成 CSV。

### v0.2（个人日常可用）

- US-06：作为开发者，我执行过的 SQL 自动保存历史，可搜索、可一键回填到编辑器。
- US-07：作为开发者，生产库在跳板机后面，我配置 SSH 主机 / 私钥后可直接经隧道连接数据库。

### v0.3+ / v1.0（能力扩展）

- US-08：作为开发者，我把查询结果一键导出为 CSV / Excel / INSERT 语句。
- US-09：作为开发者，我在网格里直接改单元格数据，应用生成 UPDATE 语句让我确认后执行。
- US-10：作为用户，我可以切换深色主题，设置默认查询行数上限。

### v0.5（表与数据同步）

- US-11：作为开发者，我选择两个连接（如开发库与测试库）中的同名表，应用比对表结构差异，逐列/逐索引列出差异明细。
- US-12：作为开发者，我可以按主键比对两张表的数据差异（新增 / 修改 / 缺失），预览将执行的同步 SQL，确认后执行或仅导出脚本，防止误同步。

## 5. 关键非功能需求

| 维度 | 要求 |
|---|---|
| 安全 | 密码使用系统钥匙串机制加密存储（Electron safeStorage），任何界面与日志不回显明文密码；后端只监听 127.0.0.1 并校验随机 Token |
| 性能 | 应用冷启动（含后端就绪）≤ 8 秒；万行结果集翻页流畅不卡 UI |
| 可靠 | 后端进程异常退出时前端给出明确提示并可重启后端；退出应用时后端进程必须被清理（不留孤儿进程） |
| 数据安全 | 查询结果集设置默认行数上限（1000 行，可配置），防止误查大表拖垮内存 |

## 6. 成功标准（v1.0）

1. 作者本人日常 MySQL 工作完全使用 Joyo，不再打开其他客户端
2. GitHub 开源后获得初始社区反馈（≥ 100 star）
3. 安装包 ≤ 150MB，空闲内存 ≤ 400MB
