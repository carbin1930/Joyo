## v0.1 验收标准（本版本 Definition of Done）

1. 安装包可安装运行；开发模式下 `pnpm dev` 一键启动完整应用
2. 可创建、编辑、删除、测试 MySQL 连接；密码加密存储，重启后可直接连接
3. 左侧树可浏览数据库 → 表 → 列，可查看表结构与 DDL
4. SQL 编辑器支持执行选中 / 全部语句，多语句按分号拆分依次执行
5. 结果网格支持分页（默认每页 100 行）、NULL 样式区分、复制为 CSV
6. 超过行数上限的查询被截断并明确提示
7. 应用退出后不遗留 Java 后端进程
8. 后端核心 Service 层有单元测试，全部通过

## v0.2 验收标准（摘要）

- 查询历史持久化到本地（SQLite），支持关键词搜索与一键回填
- 支持经 SSH 隧道（密码 / 私钥两种认证）连接数据库
- 右下角资源监控（F14）：Electron 全部子进程 + Java 后端 JVM 的内存/CPU
- 应用内日志查看（F13）：设置内嵌日志页，尾部实时滚动

|---|---|---|---|---|---|
| F12 | 表/数据同步 | 2026-10-15 | **v0.5** | 未开始 | 需求评审时补充；依赖 F04/F08 的网格与编辑能力 |

> 规则：开发中提出的新需求一律先登记本表与 PRD 功能清单、明确阶段，再按版本节奏实现；确有必要的调试类基础设施（如文件日志）允许提前落地，但需在备注中注明。

## 迭代节奏约定

- 每个版本内按 spec 逐个实现，spec 全部验收通过后打 tag（如 `v0.1.0`）
- 开发顺序固定为：spec-01 → spec-02 → spec-03 → spec-04（存在接口依赖）
- 每完成一个 spec，更新根目录 `progress.md`
